# Tarefas

Gerenciador de tarefas: tarefas com categoria, prioridade, data/horário, responsável e checklist; projetos com progresso; calendário mensal; notificações (atribuição, conclusão, cancelamento e lembrete 15 min antes); perfil e troca de senha.

- frontend/: React + Vite + Tailwind.
- backend/: Express + Prisma (PostgreSQL).
- Login inicial: `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD` do `.env` do servidor (a senha nunca vai para o repositório; sem ela o admin inicial não é criado). Outros usuários se cadastram pela tela inicial.
